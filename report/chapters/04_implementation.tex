\subsection{Implementation Strategy}
The implementation follows a bottom-to-up design flow consistent with industrial RTL practice. The process go through 4 phases: specification review, RTL coding for each individual module, functional simulation, and unit-test for debugging to ensure any failures happened only in current development module and hardware matches the intended behaviour.

Throughout the implementation, the following coding style guidelines are enforced for readability, synthesisable, maintainable Verilog source codes: maintaining consistent indentation, naming conventions (\texttt{lower\_case} variable case), and comments throughout code.
